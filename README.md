# KMR Bird

Flap-through-the-gaps game for Meta Ray-Ban Display glasses and the Meta Neural Band, with an original bird and a huge wardrobe.

- **Pinch** to flap, **Back** to pause. Grab coins in the gaps.
- Medals: Bronze 10 · Silver 20 · Gold 30 · Platinum 40 · Diamond 75 · KMR Legend 150.
- **314 items** across 10 slots: colors, hats, eyewear, face, neck, belts, pants, shoes, wings and flight trails.
- **Daily Shop**: 4 exclusives + 2 deals, the same for everyone each day (UTC). Secret items show up about 1 day in 30.
- **Monthly events**: the world and a set of limited items change every month (Halloween, Thanksgiving, Christmas…).
- **Mystery Eggs** and **Golden Eggs** with published odds, a 7-day **daily login** streak, and achievements that unlock items.
- **Quests**: 2 hourly and 3 daily quests that pay coins, plus a bonus for finishing all the daily ones.
- **Locker**: just the items you own, with your bird big on screen (Shuffle for a random outfit). Every item is in the Shop's **Permanent** tab.
- Global leaderboard (with everyone's outfit) shared with the other KMR apps; uses the same player name and **Link name** codes.

Play: https://webmanagments.github.io/kmr-bird/

## Develop

```
npm install
npm run dev        # http://localhost:5173  (/sheet.html shows every item)
npm run build      # builds into docs/ (served by GitHub Pages)
```
